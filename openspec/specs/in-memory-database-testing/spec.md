## ADDED Requirements

### Requirement: 内存数据库测试支持
系统的 `db` 模块应当支持在内存中初始化数据库连接，用于快速执行 SQL 逻辑测试。

#### Scenario: 内存中运行迁移
- **WHEN** 调用 `init_db(":memory:")`
- **THEN** 系统在内存中成功创建一个全新的 SQLite 数据库并完成所有表和迁移操作。

### Requirement: 业务逻辑测试解耦
集成测试应当能够注入一个预填充了 Mock 数据的内存数据库连接，以便在不产生任何磁盘副作用的情况下测试交易逻辑、计算逻辑和同步逻辑。

#### Scenario: 注入内存连接测试
- **WHEN** 在测试中向业务组件（如 `sync` 或 `finance` 相关的业务逻辑）注入一个内存数据库连接
- **THEN** 所有查询和写入操作都在内存中执行，且测试结束后数据自动销毁。
