# 哔哩视频下载

在 B 站视频页面右上角注入一个悬浮下载按钮，支持选择画质、编码格式并一键下载视频流与音频流。

## 功能特性

- **多画质下载**：支持 8K / 杜比视界 / HDR / 4K / 1080P60 / 1080P+ / 1080P / 720P / 480P / 360P
- **多编码格式**：AVC、HEVC、AV1，同一画质自动保留最高带宽版本
- **音频流下载**：可单独下载高品质（320kbps）、中品质（128kbps）、低品质（64kbps）音频
- **DASH 合并命令**：点击视频流后自动将 FFmpeg 合并命令复制到剪贴板
- **durl 格式支持**：部分视频（非 DASH 源）的视频与音频已合并，直接下载为 MP4
- **SPA 路由感知**：B 站单页切换时自动重新注入，无需刷新页面
- **Shadow DOM 隔离**：UI 不受 B 站全局样式影响

## 使用方法

1. 打开任意 B 站视频页面（`bilibili.com/video/...`）
2. 等待页面加载完成，右上角出现 **⬇ 下载视频** 按钮
3. 点击按钮展开面板，选择所需画质/编码的视频流进行下载
4. 若为 DASH 格式，需同时下载对应音频流，然后使用 FFmpeg 合并：

```bash
ffmpeg -i "视频标题_video.m4s" -i "视频标题_audio.m4s" -c copy "视频标题.mp4"
```

> 点击视频流选项时，合并命令会自动复制到剪贴板。

## 依赖

- 需安装 [FFmpeg](https://ffmpeg.org/) 以合并 DASH 格式的视频与音频（仅 DASH 流需要）

## 权限说明

| 权限 | 用途 |
|------|------|
| `GM_xmlhttpRequest` | 携带 Referer 请求 B 站 CDN，绕过跨域限制 |
| `GM_setClipboard` | 复制 FFmpeg 合并命令到剪贴板 |
| `GM_download` | 预留，当前版本使用 Blob URL 方式下载 |
| `unsafeWindow` | 读取页面 `__playinfo__` 变量获取视频流信息 |

## 已知限制

- 仅支持 `bilibili.com/video/*` 路径，不支持番剧、直播等页面
- 下载速度受 B 站 CDN 限速约束，高画质大文件耗时较长
- 大会员专属画质（4K/HDR/杜比等）需账号本身拥有对应权限，脚本不提供破解
