## MODIFIED Requirements

### Requirement: 模糊搜索返回多个结果时的选择策略
当远程接口返回多个结果（如 "020988", "020989"）时，系统必须根据 `interactive` 标志决定处理方式：在交互模式下提供选择列表，在非交互模式下直接返回错误。

#### Scenario: 交互模式下多个结果
- **WHEN** 用户在交互模式下输入 "南方" 且远程接口返回多个结果
- **THEN** 系统必须通过 CLI 展示一个交互式列表供用户选择，直到用户确认或退出

#### Scenario: 非交互模式下多个结果
- **WHEN** 用户在非交互模式下输入 "南方" 且远程接口返回多个结果
- **THEN** 系统不得展示交互式列表，必须直接返回明确指出匹配冲突的错误信息
