# 全平台热搜榜

获取当日中文平台热搜榜单，了解当前热门话题。

数据来源：[龙轩导航 API](http://api.ilxdh.com) 聚合了多个平台的热搜数据，无需登录即可查看。

## API 请求

```bash
curl -s 'http://api.ilxdh.com/navig/topnews/list' \
  -H 'Accept: application/json' \
  -H 'Content-Type: application/json' \
  -H 'User-Agent: Mozilla/5.0' \
  --data-raw '{"all":1}' \
  --insecure
```

## 支持平台

| 平台 | type值 | 关键词 |
|------|--------|--------|
| 微博热搜 | 1 | 微博、微博热搜 |
| 知乎热榜 | 2 | 知乎、知乎热榜、知乎热搜 |
| 头条热榜 | 3 | 头条、头条热榜、头条热搜 |
| 抖音热榜 | 4 | 抖音、抖音热榜 |
| 百度热搜 | 5 | 百度、百度热搜 |

## 使用示例

**获取微博热搜：**

```
用户: 微博热搜
回复: 📈 微博热搜榜 - 日期
      1. [标题](URL)
      ...
```

**获取知乎热榜：**

```
用户: 知乎热搜
回复: 📚 知乎热榜 - 日期
      1. [标题](URL)
      ...
```

**获取头条热搜：**

```
用户: 头条热搜
回复: 📱 头条热榜 - 日期
      1. [标题](URL)
      ...
```

**获取全平台热搜：**

```
用户: 全平台热搜 / 有什么热搜
回复: 所有平台热搜列表
```

## 输出格式

- 标题 + 原始链接
- 微博热搜链接需要 URL 编码关键词
- 知乎/头条/百度链接直接使用 API 返回的 URL

## 注意事项

- 使用 `--insecure` 参数跳过 SSL 验证
- API 返回数据可能有数分钟延迟
- 建议缓存结果避免频繁请求
